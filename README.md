## 🎓 About This Repository

This repository is a curated, verified archive of my journey through the **Microsoft Power BI Data Analyst Professional Certificate** — an 8-course specialization built to prepare data analysts for the industry-recognized **PL-300: Microsoft Power BI Data Analyst** certification exam.

Every certificate here represents hands-on, applied learning — from raw data cleaning to building polished, decision-ready dashboards.

> 💡 **Why this repo exists:** to showcase verifiable proof of skill, track my learning path, and serve as a quick-reference portfolio for recruiters, collaborators, and future me.
