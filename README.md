# Microsoft Power BI Data Analyst — Professional Certificate

Course certificates from the Microsoft Power BI Data Analyst Professional Certificate program (Coursera), completed in preparation for the **PL-300: Microsoft Power BI Data Analyst** certification exam.

**Platform:** Coursera | **Issuer:** Microsoft | **Status:** Completed (8/8 courses) | **License:** MIT

## Overview

This repository contains verified course certificates earned through the Microsoft Power BI Data Analyst Professional Certificate specialization. The program covers the complete data analytics workflow — from data preparation and transformation to modeling, visualization, and deployment — aligned with the skills measured in the PL-300 exam.
